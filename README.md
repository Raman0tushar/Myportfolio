Welcome to the repository of my personal portfolio. This project serves as a digital resume and a showcase of my journey as a Software Developer.

🌐 **[GitHub Pages](https://Raman0tushar.github.io/Myportfolio/)**

---

## ✨ Features

* **Modern UI/UX:** Clean, minimalist design using **shadcn/ui** components.
* **Responsive Design:** Fully optimized for all screen sizes (Mobile, Tablet, Desktop) using Tailwind CSS.
* **Project Showcase:** Highlights my key projects with links to live demos and source code.
* **Skills Visualization:** Interactive display of technical proficiencies.
* **Performance:** Blazing fast load times thanks to **Vite** and optimized asset management.
* **Contact Integration:** Easy ways for recruiters and collaborators to reach out.

---

## 🛠️ Tech Stack

* **Framework:** [React.js](https://reactjs.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Components:** [shadcn/ui](https://ui.shadcn.com/)
* **Icons:** [Lucide-React](https://lucide.dev/)
* **Deployment:** [Vercel](https://vercel.com/) / [GitHub Pages](https://pages.github.com/)
